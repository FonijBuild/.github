## Philosophy

1. Start with an idea.
2. Fonij gives you the right foundation.
3. Build only what matters.
4. Evolve when the product needs it.

## Core repositories

- [`fonij-cli`](https://github.com/FonijBuild/fonij-cli): product planning, generation, and project evolution
- [`fonij-catalog`](https://github.com/FonijBuild/fonij-catalog): foundations, blueprints, capabilities, recipes, and migrations
- [`product-builder-handbook`](https://github.com/FonijBuild/product-builder-handbook): documentation and practical guides
- [`product-builder-kit`](https://github.com/FonijBuild/product-builder-kit): product and engineering planning templates
